Parcel та JavaScript модулі

Це завдання запускається окремо через Parcel.

  1. Відкрий термінал у папці pages/homework/frontend-4.
  2. Виконай команду npm start.
  3. Відкрий адресу http://localhost:1234.
  4. Натисни кнопку «Натисни мене» — заголовок має змінитися.

Для перевірки готової збірки виконай npm run build.
