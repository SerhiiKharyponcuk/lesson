JS-004 - Package.json setup

This is the Frontend 4 Homework 4 task for initializing a Node.js project in the current folder. The task shows how to create package.json and main.js, then run the project with npm start.

package.json

{
  "name": "frontend-4-node-project",
  "version": "1.0.0",
  "description": "Simple Node.js project in Frontend 4",
  "main": "main.js",
  "scripts": {
    "start": "node main.js"
  },
  "author": "Your Name",
  "license": "ISC"
}

main.js

console.log("Hello! This is your first Node.js project!");
